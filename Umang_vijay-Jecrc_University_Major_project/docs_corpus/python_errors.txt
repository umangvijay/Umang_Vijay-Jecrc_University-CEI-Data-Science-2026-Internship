COMMON PYTHON ERRORS AND FIXES — REFERENCE
=============================================

KEYERROR
--------
Error: KeyError: 'column_name'
Cause: The column name doesn't exist in the DataFrame.
Fix:
  # Check available columns
  print(df.columns.tolist())
  # Use case-insensitive matching
  col = [c for c in df.columns if 'target' in c.lower()]
  # Or use df.get() to avoid error
  value = df.get('column_name', default_value)

TYPEERROR
---------
Error: TypeError: unsupported operand type(s) for +: 'int' and 'str'
Cause: Mixing numeric and string types in operations.
Fix:
  # Convert to numeric
  df['col'] = pd.to_numeric(df['col'], errors='coerce')
  # Or convert to string
  df['col'] = df['col'].astype(str)

Error: TypeError: 'NoneType' object is not iterable
Cause: Function returned None when a value was expected.
Fix: Check for None before iterating:
  result = some_function()
  if result is not None:
      for item in result: ...

VALUEERROR
----------
Error: ValueError: could not convert string to float: 'abc'
Cause: Non-numeric string in a column expected to be numeric.
Fix:
  df['col'] = pd.to_numeric(df['col'], errors='coerce')

Error: ValueError: Length of values does not match length of index
Cause: Assigning a list/array of wrong length to a DataFrame column.
Fix: Ensure the assigned data has the same length as df.

Error: ValueError: cannot reindex from a duplicate axis
Cause: DataFrame has duplicate index values.
Fix: df = df.reset_index(drop=True)

INDEXERROR
----------
Error: IndexError: single positional indexer is out-of-bounds
Cause: Using .iloc with an index >= length of DataFrame.
Fix: Check length first: if len(df) > index: df.iloc[index]

ATTRIBUTEERROR
--------------
Error: AttributeError: 'Series' object has no attribute 'columns'
Cause: Treating a Series as a DataFrame.
Fix: Use double brackets for DataFrame: df[['col']] instead of df['col']

Error: AttributeError: Can only use .dt accessor with datetimelike values
Cause: Column is not datetime type.
Fix: df['col'] = pd.to_datetime(df['col'], errors='coerce')

Error: AttributeError: 'DataFrame' object has no attribute 'append'
Cause: df.append() was removed in pandas 2.0.
Fix: Use pd.concat([df1, df2]) instead.

FUTUREWARNING AND DEPRECATION
------------------------------
Warning: FutureWarning: The default value of numeric_only in groupby.sum() is deprecated
Fix: Explicitly pass numeric_only=True:
  df.groupby('col').sum(numeric_only=True)
  df.groupby('col').mean(numeric_only=True)

Warning: FutureWarning: DataFrame.fillna with 'method' is deprecated
Fix: Use df.ffill() or df.bfill() instead of df.fillna(method='ffill')

Warning: SettingWithCopyWarning
Cause: Modifying a copy of a slice.
Fix: Use .loc for assignment:
  df.loc[df['A'] > 5, 'B'] = 10
Or use .copy() when slicing:
  subset = df[df['A'] > 5].copy()

MATPLOTLIB ERRORS
-----------------
Error: RuntimeError: main thread is not in main loop
Fix: Set backend before importing pyplot:
  import matplotlib
  matplotlib.use('Agg')
  import matplotlib.pyplot as plt

Error: UserWarning: Matplotlib is currently using agg
Info: This is normal for server/subprocess environments. Charts save correctly.

PLOTLY ERRORS
-------------
Error: ValueError: No data found. Check data input.
Fix: Ensure DataFrame is not empty and columns exist:
  if not df.empty and 'col' in df.columns:
      fig = px.bar(df, x='col', y='value')

SKLEARN ERRORS
--------------
Error: ValueError: Input contains NaN
Fix: Drop or fill NaN before fitting:
  df = df.dropna(subset=['feature_col', 'target_col'])
  # Or
  df['col'] = df['col'].fillna(df['col'].median())

Error: ValueError: could not convert string to float
Fix: Encode categorical variables:
  from sklearn.preprocessing import LabelEncoder
  le = LabelEncoder()
  df['encoded'] = le.fit_transform(df['category'])

STATSMODELS ERRORS
------------------
Error: ValueError: endog and exog values must not contain NaN
Fix: Remove NaN values before fitting ARIMA:
  clean_data = data.dropna()

Error: LinAlgError: SVD did not converge
Fix: Try different ARIMA orders or reduce data complexity:
  try:
      model = ARIMA(data, order=(1,1,1))
  except Exception:
      model = ARIMA(data, order=(0,1,1))

GENERAL TIPS
------------
1. Always check df.columns.tolist() before accessing columns.
2. Use errors='coerce' with pd.to_numeric() and pd.to_datetime().
3. Check df.dtypes before performing operations.
4. Use .copy() when creating subsets to avoid SettingWithCopyWarning.
5. Use numeric_only=True in aggregation functions for pandas 2.0+.
6. Use matplotlib.use('Agg') for non-GUI environments.
7. Always close figures with plt.close(fig) after saving.
